# Reviewer Guide

This is a bounded, read-only review of the published GEFOS Phase 2 materials.

## What to do

1. Read the Phase 2 scope and checklist materials in this repository.
2. Use the questions in the README to assess clarity, completeness, recoverability, and operational usability.
3. Report each actionable finding separately using the GitHub issue form.
4. Mark recommendations as blocking or non-blocking and explain why.
5. Do not test or access the production system.

## What not to do

- Do not request or use credentials.
- Do not probe any live host, API, or infrastructure.
- Do not include private or identifying data in issues.
- Do not treat a review comment or pull request as authorization to change production.

The repository owner will triage findings, decide which changes to make, and update the review packet when appropriate.
